Projekt-CSS

Im VIS-2-Editor unter Projekt → CSS einfügen und bei jedem Widget im Feld CSS-Klasse gh-glass eintragen. Skulptur und Skyline liegen als eigene Skripte im Ordner vis2-glashaus/src (sculpture.js, skyline.js) und laufen in einem HTML-Widget.

/* Glashaus – VIS 2 Projekt-CSS */
.gh-page{
  background:#ebe9e5;
  color:#151514;
  font-family:"Geist",-apple-system,"Helvetica Neue",sans-serif;
}
.gh-glass{
  background:rgba(255,255,255,.34)!important;
  -webkit-backdrop-filter:blur(26px) saturate(150%);
  backdrop-filter:blur(26px) saturate(150%);
  border-radius:26px!important;
  box-shadow:inset 0 1px 0 rgba(255,255,255,.9),
    inset 0 0 0 1px rgba(255,255,255,.55),
    0 30px 60px -34px rgba(60,48,28,.2)!important;
  transition:transform .5s cubic-bezier(.34,1.56,.64,1),
    background .45s,color .45s;
}
.gh-glass:active{transform:scale(.96)}
/* Zustand „an“: Tinte statt Glas */
.gh-on{background:#151514!important;color:#ebe9e5}

.gh-serif{

  font-style:italic;font-weight:400;

@media (prefers-reduced-motion:reduce){
  .gh-rise,.gh-spin svg{animation:none!important}
}
