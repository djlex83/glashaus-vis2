Projekt-CSS

Dasselbe Projekt-CSS wie in der Ansicht Zuhause. Der Energiefluss ist ein Canvas-Skript; für VIS reicht als einfache Variante eine SVG-Linie mit der Klasse gh-flow.

/* Energiefluss-Linie (SVG im HTML-Widget) */
.gh-flow{
  stroke-dasharray:2 14;
  stroke-linecap:round;
  animation:gh-flow 1.2s linear infinite;
}
/* Gegenrichtung, z. B. Netzbezug statt Einspeisung */
.gh-flow.rev{animation-direction:reverse}
@keyframes gh-flow{to{stroke-dashoffset:-16}}

/* Batterie als Flüssigkeit: --soc per Binding setzen */
.gh-liquid{position:relative;overflow:hidden;border-radius:30px}
.gh-liquid::before{
  content:"";position:absolute;left:50%;
  width:420px;height:420px;margin-left:-210px;
  top:calc(100% - var(--soc,50) * 1% - 8px);
  border-radius:42%;background:#3a8452;
  animation:gh-wave 9s linear infinite;
}
@keyframes gh-wave{to{transform:rotate(360deg)}}

@media (prefers-reduced-motion:reduce){
  .gh-flow,.gh-liquid::before{animation:none!important}
}

Ladestand als Variable, z. B. im Feld Stil: --soc:{bydhvs.0.State.SOC}
