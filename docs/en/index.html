Project CSS

In the VIS 2 editor, paste under Project → CSS and enter in every widget’s CSS class field gh-glass . Sculpture and skyline are separate scripts in the folder vis2-glashaus/src (sculpture.js, skyline.js) and run in an HTML widget.

/* Glashaus – VIS 2 project CSS */
.gh-page{
  background:#ebe9e5;
  color:#151514;
  font-family:"Geist",-apple-system,"Helvetica Neue",sans-serif;
}
.gh-glass{
  background:rgba(255,255,255,.34)!important;
  -webkit-backdrop-filter:blur(26px) saturate(150%);
  backdrop-filter:blur(26px) saturate(150%);
  border-radius:26px!important;
  box-shadow:inset 0 1px 0 rgba(255,255,255,.9),
    inset 0 0 0 1px rgba(255,255,255,.55),
    0 30px 60px -34px rgba(60,48,28,.2)!important;
  transition:transform .5s cubic-bezier(.34,1.56,.64,1),
    background .45s,color .45s;
}
.gh-glass:active{transform:scale(.96)}
/* State “on”: ink instead of glass */
.gh-on{background:#151514!important;color:#ebe9e5}

.gh-serif{
  font-family:"Instrument Serif",serif;
  font-style:italic;font-weight:400;
}
.gh-rise{animation:gh-rise 1s cubic-bezier(.2,.7,.2,1) both}
@keyframes gh-rise{from{opacity:0;transform:translateY(18px);filter:blur(6px)}}

.gh-spin svg{animation:gh-spin 1.4s linear infinite}
@keyframes gh-spin{to{transform:rotate(360deg)}}

@media (prefers-reduced-motion:reduce){
  .gh-rise,.gh-spin svg{animation:none!important}
}

Switch state as a class, e.g. in the CSS class field: gh-glass {v:shelly.0.SHSW-25#421DC5EC0DB4#1.Relay0.Switch; v ? 'gh-on' : ''}
