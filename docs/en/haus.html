Notes

The model is a canvas script and runs in VIS 2 in an HTML widget. The room outlines are a table in the script (metres; here a fictional sample house, your own floor plans can be entered the same way) and can be adjusted there.

For ioBroker it is worth also creating the rooms as enumerations (enum.rooms). Then any script can find devices by room, e.g. “all lights in the attic off”.
